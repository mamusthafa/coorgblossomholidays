# Coorg Blossom Holidays – Complete Website Development Workplan

Static HTML Website | GitHub Pages | Google Ads Landing Pages | Local SEO | Mobile-First Design

The website for Coorg Blossom Holidays should function as a professional tourism and transport booking platform, with two clearly separated services: Taxi Services in Madikeri & Coorg and Homestay Booking in Coorg.

The primary objective is to convert visitors coming from Google Search Ads, Google Maps, and organic search into direct phone calls and WhatsApp enquiries.

The website should be fast, visually appealing, fully mobile responsive, SEO-friendly, and easy to maintain on GitHub Pages.

### Google Ads conversion tracking

Track these events separately:

| Conversion event          | Recommended measurement                                  |
| ------------------------- | -------------------------------------------------------- |
| Click-to-call button      | Secondary initially; qualified calls can become primary  |
| Calls from Google Ads     | Primary when minimum duration and quality are configured |

| Completed lead form       | Primary if a successful submission can be verified       |
| Qualified booking enquiry | Primary when recorded through a reliable lead process    |

For WhatsApp, a click does not prove that the customer sent a message. Track it as a separate interaction unless you have a system that verifies the completed enquiry.
